# 通用下拉框实施与验证记录

## 范围

- 新增 `src/renderer/src/components/Select.tsx` 和 `styles/select.css`。
- 以首页记录库原生下拉框为样式基准：统一圆角、边框、箭头、主题变量、悬停、焦点和禁用状态。
- regular 高度 44px、compact 高度 38px；可选前置图标，图标/箭头不接收鼠标事件，不额外加入 Tab 顺序。
- 原生属性、事件、子选项和 ref 传给实际 select。原生 fieldset 禁用由浏览器处理，CSS 使用 :disabled，不另建一套 React 禁用状态。
- 选项列表仍由系统/Chromium 绘制，不引入自定义弹层、列表框、定位或第三方组件依赖。

## 接入与兼容

- DataActionsPanel：保留记录库、数据库图标及原有禁用条件，使用 regular。
- HardwareSettings：固定选项使用 compact，覆盖波特率、串口格式、扫描结果、数据/校验/停止位、连接接口、阵列连接方式与 REV、模块类型、通道和读取方式。
- ExperimentSettings：默认记录库使用 regular。
- 移除 data-actions、hardware 和 settings 中重复的 select 外观规则；保留输入框样式及首页主题配色覆盖。
- 所有旧选项、空值、旧配置提示、类型转换、联动和业务回调保持原样。
- 波特率后续统一为 Select：所有设备（含电机）共用 1200/2400/4800/9600/19200/38400/115200 七档；空值/原默认值/旧配置均不自动覆盖。单位的 input+datalist 及端口手工输入仍保留。
- 不修改配置结构、硬件协议、IPC 或自动连接；不包含此前未提交清理工作的自动提交。
