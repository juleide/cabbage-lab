# 64 × 64 阵列采集与云图显示改造

## 目标与边界

云图改为 Python 完整阵列 → Electron 最新帧事件 → Canvas 绘制。完成连续字节解析、点位重排、拼帧、Python 模拟源和显示节流；本轮不接真实 USB、不推测厂家 CRC 或压力标定、不保存阵列历史。电机控制、标量记录和 CSV 导出保持不变。

## Python 阵列模块

- 增量缓存字节流，处理半包、粘包、包前噪声，按 `AA 10 33` 找包头，整包长度 136 字节。
- 校验行号和 CRC，高字节在前读取 64 个原始 16 位数据。列号映射为 `(数据索引 % 8) × 8 + 数据索引 // 8`。
- 仅缓存一个待组装帧，允许帧内行乱序，重复行不重复计数，集齐 64 行才发布。组帧超时 500ms；新帧到来或超时丢弃残帧，不借用旧行。
- 按模 256 识别帧号循环，源重启或模式切换时重置解析缓存。统计有效帧、CRC 失败及残帧丢弃，不逐包写日志。
- CRC 通过策略注入。模拟约定使用 CRC-16/CCITT-FALSE（poly=0x1021，init=0xFFFF，refin/refout=false，xorout=0），覆盖 CRC 前全部字节，结果高字节在前。此约定不代表厂家协议，真实数据源保持关闭。
- 解析器保留原始 16 位数据，不擅自确定负数编码、电压比例或压力换算。
- Python 按压／抓取模拟公式生成 0～4095 阵列，编码成行包，再经过同一解析、校验和拼帧流程。默认采集 25Hz，独立工作线程、有界最新帧缓存，不在采集线程操作控制状态或 SQLite，退出时停止线程。

## 通信与调度

- 新增 PressureFrame：发布序号、设备帧号、采集时间、固定宽高 64 × 64、行优先 4096 点数组、模式、simulation 来源。
- 新增 `pressure.frame` 最新完整帧事件及 `pressure.mode` 模拟模式请求；初始快照提供最近完整帧和模式。
- 发布上限 10Hz，独立于标量 sampleIntervalMs。阵列事件单独一个覆盖式槽位，不进入可靠响应队列；控制响应和急停／停止优先。
- 前端独立 hook 订阅阵列，用 ref 保存最新值。Canvas 只绘制最新帧，不用阵列数据驱动整个首页重渲染。沿用 JSONL，不新增网络服务或共享内存。

## 显示行为

- 保留云图布局、放大尺寸、模式按钮及色标。移除前端分布公式，使用收到的完整阵列和固定 0～4095 范围映射颜色。
- 色标改为相对强度百分比，明确模拟阵列，不再显示未经标定的 kPa。
- 模式切换交由 Python 确认；切换期间清除旧图，收到匹配的新帧再显示。
- 置零使模拟阵列归零；急停清空并提示采集暂停。
- 无完整帧提示等待；离线或超过 1 秒无新帧时淡化最后画面并提示，不继续标为实时。已有标量参数不从阵列推算实际面积或力。

## 实施与验收

1. 解析器、CRC 策略、拼帧器及模拟源。
2. 采集线程、有界缓存、独立发布调度。
3. 共享类型、Electron 转发和前端订阅。
4. Canvas 数据源、模式切换、暂停和失联展示。
5. 更新 README 与实施状态。

不新增测试套件。仅类型检查、构建和一次短流程确认：分块组帧、错误校验、缺行、重排、帧号循环、模式切换、置零与急停；确认不修改数据库结构及导出行为。现有工具检查随接口变化更新，避免保留失效用例。

真实设备接入需另外确认 USB 类型／驱动、厂家 CRC、符号编码、电压与压力换算及按压／抓取来源对应关系。

## 实施状态

本轮已完成（2026-10-28）：

- 新增独立采集线程，25Hz 模拟字节流通过实际解析器拼帧；仅保留一份最新完整帧，不访问 SQLite。
- JSONL 增加阵列覆盖槽位，响应／状态在阵列之前发送；阵列发布最多 10Hz，独立于标量采样设置。
- 共享类型、pressure.mode、pressure.frame 和初始快照已接入。React 用独立订阅和 ref 保存阵列，Canvas 按最新帧绘图。
- 已替换前端模拟公式，增加相对强度标识、切换等待、暂停、超时与离线展示。
- 类型检查、构建及既有两项轻量工具检查通过。复用现有 backend:check 短流程确认拆包、CRC、点位重排、帧号循环、模式切换、置零、暂停、独立刷新和原有记录保留，未新增测试套件。
- 短流程同时修正了保存采样间隔后旧调度时间未及时更新的问题，使配置按新间隔生效。

真实 USB、厂家 CRC 和压力标定未实现，不属于本轮验收。未进行真实设备联调；图形界面仍需在本机运行后查看实际显示，不将构建成功视为视觉验收。
