# 57 步进电机：力川 RS485 单轴驱动控制协议

更新日期：2026-10-30。

本文已清空旧内容，依据本次用户提供的协议总结重新整理，仅包含 RS485 单轴驱动器的通信、寄存器、控制方式和报文。本文未重新核对厂家原始手册；示例 CRC 已离线核算，不代表完成实机测试。

## 1. 通信配置

该系列通过 RS485 总线使用 Modbus RTU 主从通信，不支持 Modbus ASCII。

| 项目 | 配置 / 定义 |
| --- | --- |
| 物理接口 | RS485，半双工 |
| 通信方式 | 主机发起请求，从机应答；从机之间不直接通信 |
| 协议 | Modbus RTU，报文按二进制字节发送，不发送十六进制文本 |
| 波特率 | 9600、19200、38400、115200 bit/s，通过 SW6、SW7 设置 |
| 拨码站号 | 1～31，通过 SW1～SW5 设置 |
| 自定义站号参数 | PA_020，地址 `0x0020`（十进制 32），参数范围 0～254 |
| 广播地址 | 报文 ID `00`；不用于需要应答的设备连接验证 |
| 串口格式参数 | PA_021，地址 `0x0021`（十进制 33）；可设置数据位、校验位和停止位，默认无校验 |
| CRC | CRC-16/MODBUS，结果低字节在前、高字节在后 |
| 终端电阻 | SW8 为 ON 时接入 120 Ω，总线末端驱动器按总线接线使用 |
| 最大信息长度 | 100 byte |

同一 RS485 总线上的设备应使用相同的波特率和串口格式，各设备使用唯一站号。多个电机驱动器共用一个串口，主机按站号访问。

自定义地址用于拨码以外的配置；参数范围 0～254 不等于总线允许接入 254 台设备，也不能据此推断超过 32 个节点时的电气容量。地址 0 保留作广播，普通单机请求使用非广播地址。

本次提供的总结未列出 PA_021 各枚举值对应的完整串口格式，不在此补写数值映射。

## 2. 地址与数据表示

- 参数名中的编号按十六进制理解，例如 PA_04E 对应 `0x004E`，即十进制 78。
- 报文中的寄存器地址和每个 16 位数据均为高字节在前、低字节在后。
- 32 位定位目标分成两个 16 位寄存器：高字在前，低字在后。
- CRC 与寄存器数据的字节顺序不同，CRC 低字节先发送。
- 使用本文给出的协议地址，不额外添加 `40001`，也不对地址加减 1。

| 参数 / 数据 | 协议地址（HEX） | 十进制地址 |
| --- | --- | --- |
| 状态字 PA_004 | `0x0004` | 4 |
| 当前位置高字 / 低字 | `0x0008` / `0x0009` | 8 / 9 |
| 当前速度 | `0x000A` | 10 |
| 自定义站号 PA_020 | `0x0020` | 32 |
| 串口格式 PA_021 | `0x0021` | 33 |
| 细分参数（见写入示例） | `0x0023` | 35 |
| JOG 参数组 PA_030～PA_032 | `0x0030`～`0x0032` | 48～50 |
| 定位参数组 PA_033～PA_038 | `0x0033`～`0x0038` | 51～56 |
| 定位目标高字 PA_037 | `0x0037` | 55 |
| 定位目标低字 PA_038 | `0x0038` | 56 |
| 回零参数组 PA_040～PA_045 | `0x0040`～`0x0045` | 64～69 |
| 控制字 PA_04E | `0x004E` | 78 |
| 辅助控制 PA_04F | `0x004F` | 79 |

注意：报文中的 `00 23` 是地址 `0x0023`，不是十进制 23；`00 37` 是地址 `0x0037`，不是十进制 37。

## 3. Modbus 功能码与帧格式

| 功能码 | 操作 |
| --- | --- |
| `0x03` | 读取一个或多个寄存器 |
| `0x06` | 写入单个寄存器 |
| `0x10` | 连续写入多个寄存器 |

### 3.1 请求和正常应答

```text
03 请求：ID 03 地址Hi 地址Lo 数量Hi 数量Lo CRClo CRChi
03 应答：ID 03 数据字节数 [寄存器Hi 寄存器Lo ...] CRClo CRChi

06 请求：ID 06 地址Hi 地址Lo 数值Hi 数值Lo CRClo CRChi
06 应答：正常时原样回显请求

10 请求：ID 10 地址Hi 地址Lo 数量Hi 数量Lo 数据字节数 [寄存器Hi 寄存器Lo ...] CRClo CRChi
10 应答：ID 10 地址Hi 地址Lo 数量Hi 数量Lo CRClo CRChi
```

`0x10` 的正常应答不回显全部数据，只返回起始地址和寄存器数量。

### 3.2 CRC 算法

- 初值：`0xFFFF`。
- 反射多项式：`0xA001`，逐位右移。
- 最终异或：`0x0000`。
- 计算范围：从 ID 到数据末尾，不包含 CRC 自身。
- 发送顺序：`CRClo CRChi`。

更改站号、地址、数量或数据后，必须重新计算 CRC。

### 3.3 异常应答

功能码最高位置 1，例如 `0x06` 的异常功能码为 `0x86`。

```text
ID (请求功能码 | 80) 异常码 CRClo CRChi
```

| 异常码 | 本次提供总结中的含义 |
| --- | --- |
| `0x01` | 错误功能码 / CRC |
| `0x02` | 错误地址 |
| `0x03` | 错误数据 |
| `0x04` | 拒绝执行 |

接收端应校验站号、功能码、长度、CRC，并区分正常应答和异常应答；不能假定错误 CRC 一定有应答。

## 4. 控制字 PA_04E

地址：`0x004E`，十进制 78。通过写入位组合触发动作。

| 位 | 掩码 | 功能 | 定义 |
| --- | --- | --- | --- |
| Bit0 | `0x0001` | 定位触发 | 写 1 触发定位运行 |
| Bit1 | `0x0002` | 定位模式 | 0：相对位置；1：绝对位置 |
| Bit2 | `0x0004` | 指令切换 | 0：忽略新指令；1：打断当前运动并执行新指令 |
| Bit3 | `0x0008` | JOG 触发 | 写 1 触发点动运行 |
| Bit4 | `0x0010` | 回零触发 | 写 1 触发回零 |
| Bit5 | `0x0020` | 停止 | 写 1 停止当前运动 |
| Bit6 | `0x0040` | 急停 | 写 1 触发最高优先级急停 |

按本次提供总结，动作触发位写 1 有效，无需手动清零，重复触发可重新写 1。程序应将此规则限定于当前单轴协议，不套用其他驱动器。

常用控制字：

| 数值 | 动作 |
| --- | --- |
| `0x0001` | 触发相对定位，不打断当前运动 |
| `0x0003` | 触发绝对定位，不打断当前运动 |
| `0x0005` | 触发相对定位，允许打断当前运动 |
| `0x0007` | 触发绝对定位，允许打断当前运动 |
| `0x0008` | 触发 JOG |
| `0x0010` | 触发回零 |
| `0x0020` | 停止 |
| `0x0040` | 急停 |

以上数值由位定义组合得出。软件急停命令不是硬接线急停，也不应把它作为自动故障恢复或自动复位步骤。

## 5. 状态字 PA_004

地址：`0x0004`，十进制 4，通过功能码 `0x03` 读取。

| 位 | 掩码 | 状态含义 |
| --- | --- | --- |
| Bit0 | `0x0001` | 到位 |
| Bit1 | `0x0002` | 回零完成 |
| Bit2 | `0x0004` | 电机运行中 |
| Bit3 | `0x0008` | 故障 |
| Bit4 | `0x0010` | 电机使能 |
| Bit5 | `0x0020` | 正软限位 |
| Bit6 | `0x0040` | 负软限位 |

例如，判断到位使用 `(status & 0x0001) != 0`，判断运行中使用 `(status & 0x0004) != 0`，判断故障使用 `(status & 0x0008) != 0`。

写命令收到应答仅说明寄存器写入得到响应，不代表运动完成；运行结果通过状态字及位置反馈判断。

## 6. 运动参数

### 6.1 定位参数 PA_033～PA_038

参数组用于配置起始速度、加速时间、减速时间、运行速度和 32 位定位目标。提供的总结列出起始速度范围为 0～3000 r/min。

定位目标的两个寄存器：

| 地址 | 内容 |
| --- | --- |
| PA_037 / `0x0037` | 目标脉冲数高 16 位 |
| PA_038 / `0x0038` | 目标脉冲数低 16 位 |

例如，1000 pulse = `0x000003E8`：高字为 `0x0000`，低字为 `0x03E8`。使用 `0x10` 一次写入两个寄存器，再写控制字触发定位。

### 6.2 JOG 参数 PA_030～PA_032

设置 JOG 速度、加速时间、减速时间，然后向控制字写入 `0x0008` 触发。

### 6.3 回零参数 PA_040～PA_045

参数组用于配置回零方式、回零速度、爬行速度、加减速时间及原点偏移。各字段的具体地址、宽度和时间单位未在本次提供总结中逐项展开，不自行补齐。

| 回零方式值 | 含义 |
| --- | --- |
| 17 | 负限位回零 |
| 18 | 正限位回零 |
| 24 | 正向原点回零 |
| 29 | 反向原点回零 |
| 35 | 当前位置清零 |

## 7. 辅助控制 PA_04F

地址：`0x004F`，十进制 79，使用 `0x06` 写入以下命令值。

| 命令值 | 操作 |
| --- | --- |
| `0x0100` | 恢复出厂参数 |
| `0x0200` | 保存当前参数 |
| `0x0300` | 清除当前告警 |
| `0x0400` | 清除当前位置 |
| `0x0500` | 电机使能 |
| `0x0600` | 电机释放 |

需要持久化的参数修改后，使用 `0x0200` 保存；不应在每次运动指令后自动保存。

`0x0600` 按本次总结中的命令表表示“电机释放”，不是“电机锁轴”。原示例标题与命令表冲突，本文将示例统一为“电机释放”。

## 8. 内部多段控制

| 模式 | 参数范围 | DI 端子配置与触发 |
| --- | --- | --- |
| 内部多段位置 | PA_050～PA_0AE | 配置“位置路径触发”和“路径选择开关 0～3”，由 DI 电平组合选择并触发预存位置参数 |
| 内部多段速度 | PA_0B0～PA_0DF | 配置“速度路径触发”和“路径选择开关 0～3”，由 DI 电平组合选择并触发预存速度参数 |

本次提供总结将两类模式均称为 15 段。本文保留该说法，不根据参数区间自行扩展段数，也不补写未提供的分段寄存器布局。

## 9. 完整报文示例

以下站号均为 `01`。报文全部按 HEX 展示；10 条请求 / 应答的 CRC 已离线核算通过。

### 9.1 读取当前速度

起始地址 `0x000A`（十进制 10），读取 1 个寄存器。

```text
发送：01 03 00 0A 00 01 A4 08
应答：01 03 02 00 C6 38 16
```

示例数值：`0x00C6` = 198 r/min。

### 9.2 读取当前位置

起始地址 `0x0008`（十进制 8），读取 2 个寄存器，高字在前。

```text
发送：01 03 00 08 00 02 45 C9
应答：01 03 04 00 00 13 88 F7 65
```

示例数值：`0x00001388` = 5000 pulse。

### 9.3 修改细分为 1000

地址 `0x0023`（十进制 35），写入 `0x03E8`。

```text
发送：01 06 00 23 03 E8 78 BE
应答：01 06 00 23 03 E8 78 BE
```

### 9.4 触发相对定位

向控制字 `0x004E`（十进制 78）写入 `0x0001`。

```text
发送：01 06 00 4E 00 01 28 1D
```

### 9.5 保存参数

向辅助控制 `0x004F`（十进制 79）写入 `0x0200`。

```text
发送：01 06 00 4F 02 00 B9 7D
```

### 9.6 电机释放

向辅助控制 `0x004F`（十进制 79）写入 `0x0600`。

```text
发送：01 06 00 4F 06 00 BB BD
```

### 9.7 设置定位目标为 1000 pulse

从 `0x0037`（十进制 55）开始写入 2 个寄存器：高字 `0x0000`，低字 `0x03E8`。

```text
发送：01 10 00 37 00 02 04 00 00 03 E8 B1 E3
应答：01 10 00 37 00 02 F0 06
```

该操作只写入定位目标，不自动启动运动；随后写控制字才能触发定位。

## 10. 程序接入顺序

1. 为电机类型建立一个串口连接，配置与驱动器一致的波特率及串口格式。
2. 同一总线按唯一站号访问设备，一个请求完成或超时后再发送下一个请求。
3. 使用 `0x03` 读取状态字、当前位置和速度，验证通信；连接时不自动发送运动或辅助控制命令。
4. 需要运行时，先配置相应运动参数，确认写入应答，再写 PA_04E 触发。
5. 轮询 PA_004 及位置反馈，判断运行、到位、回零完成和故障。
6. 按操作需求发送停止、急停或辅助控制；不因通信超时自动重发运动触发命令。

连接页仅需：共用串口、波特率、串口格式、各驱动器站号。当前单轴连接不要求用户选择 CL / OL 型号；本文不包含双轴驱动器协议。
