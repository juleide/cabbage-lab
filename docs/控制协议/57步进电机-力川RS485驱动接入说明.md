## 1. 通信配置

该系列通过 RS485 总线使用 Modbus RTU 主从通信，不支持 Modbus ASCII。

| 项目 | 配置 / 定义 |
| --- | --- |
| 物理接口 | RS485，半双工 |
| 通信方式 | 主机发起请求，从机应答；从机之间不直接通信 |
| 协议 | Modbus RTU，报文按二进制字节发送，不发送十六进制文本 |
| 波特率 | 9600、19200、38400、115200 bit/s，通过 SW6、SW7 设置 |
| 拨码站号 | 1～31，通过 SW1～SW5 设置 |
| 自定义站号参数 | PA_020，地址 `0x0020`（十进制 32），参数范围 0～254 |
| 广播地址 | 报文 ID `00`；不用于需要应答的设备连接验证 |
| 串口格式参数 | PA_021，地址 `0x0021`（十进制 33）；可设置数据位、校验位和停止位，默认无校验 |
| CRC | CRC-16/MODBUS，结果低字节在前、高字节在后 |
| 终端电阻 | SW8 为 ON 时接入 120 Ω，总线末端驱动器按总线接线使用 |
| 最大信息长度 | 100 byte |

同一 RS485 总线上的设备应使用相同的波特率和串口格式，各设备使用唯一站号。多个电机驱动器共用一个串口，主机按站号访问。

自定义地址用于拨码以外的配置；参数范围 0～254 不等于总线允许接入 254 台设备，也不能据此推断超过 32 个节点时的电气容量。地址 0 保留作广播，普通单机请求使用非广播地址。

原手册第 21 页补齐 PA_021 枚举：0＝8N1，1＝8N2，2＝8E1，3＝8O1。连接配置必须匹配实物；不在连接时自动写 PA_021。

## 2. 地址与数据表示

- 参数名中的编号按十六进制理解，例如 PA_04E 对应 `0x004E`，即十进制 78。
- 报文中的寄存器地址和每个 16 位数据均为高字节在前、低字节在后。
- 当前位置及定位目标均为有符号 int32，高字在前；当前速度为有符号 int16，单位 r/min（第 11 页）。
- 合并原始位值 `u = (high << 16) | low`；有符号位置为 `u`（u < 0x80000000）或 `u - 0x100000000`。负目标按 32 位补码拆分；例如 -1000 为 `FFFF FC18`，原手册第 12 页有对应报文。
- 第 19 页明确：开环时当前位置是给定指令位置，闭环时为反馈位置。读取成功不等于机械到达，不能直接以该寄存器证明没有失步。
- pulse 转换为机械 mm 仍需实物细分、传动机构和方向标定；手册示例的每圈 1000 pulse 不是现场已确认值。
- CRC 与寄存器数据的字节顺序不同，CRC 低字节先发送。
- 使用本文给出的协议地址，不额外添加 `40001`，也不对地址加减 1。

| 参数 / 数据 | 协议地址（HEX） | 十进制地址 |
| --- | --- | --- |
| 状态字 PA_004 | `0x0004` | 4 |
| 当前位置高字 / 低字 | `0x0008` / `0x0009` | 8 / 9 |
| 当前速度 | `0x000A` | 10 |
| 自定义站号 PA_020 | `0x0020` | 32 |
| 串口格式 PA_021 | `0x0021` | 33 |
| 细分参数（见写入示例） | `0x0023` | 35 |
| JOG 参数组 PA_030～PA_032 | `0x0030`～`0x0032` | 48～50 |
| 定位参数组 PA_033～PA_038 | `0x0033`～`0x0038` | 51～56 |
| 定位目标高字 PA_037 | `0x0037` | 55 |
| 定位目标低字 PA_038 | `0x0038` | 56 |
| 回零参数组 PA_040～PA_045 | `0x0040`～`0x0045` | 64～69 |
| 控制字 PA_04E | `0x004E` | 78 |
| 辅助控制 PA_04F | `0x004F` | 79 |

注意：报文中的 `00 23` 是地址 `0x0023`，不是十进制 23；`00 37` 是地址 `0x0037`，不是十进制 37。

## 3. Modbus 功能码与帧格式

| 功能码 | 操作 |
| --- | --- |
| `0x03` | 读取一个或多个寄存器 |
| `0x06` | 写入单个寄存器 |
| `0x10` | 连续写入多个寄存器 |

### 3.1 请求和正常应答

```text
03 请求：ID 03 地址Hi 地址Lo 数量Hi 数量Lo CRClo CRChi
03 应答：ID 03 数据字节数 [寄存器Hi 寄存器Lo ...] CRClo CRChi

06 请求：ID 06 地址Hi 地址Lo 数值Hi 数值Lo CRClo CRChi
06 应答：正常时原样回显请求

10 请求：ID 10 地址Hi 地址Lo 数量Hi 数量Lo 数据字节数 [寄存器Hi 寄存器Lo ...] CRClo CRChi
10 应答：ID 10 地址Hi 地址Lo 数量Hi 数量Lo CRClo CRChi
```

`0x10` 的正常应答不回显全部数据，只返回起始地址和寄存器数量。

### 3.2 CRC 算法

- 初值：`0xFFFF`。
- 反射多项式：`0xA001`，逐位右移。
- 最终异或：`0x0000`。
- 计算范围：从 ID 到数据末尾，不包含 CRC 自身。
- 发送顺序：`CRClo CRChi`。

更改站号、地址、数量或数据后，必须重新计算 CRC。

### 3.3 异常应答

功能码最高位置 1，例如 `0x06` 的异常功能码为 `0x86`。

```text
ID (请求功能码 | 80) 异常码 CRClo CRChi
```

| 异常码 | 本次提供总结中的含义 |
| --- | --- |
| `0x01` | 错误功能码 / CRC |
| `0x02` | 错误地址 |
| `0x03` | 错误数据 |
| `0x04` | 拒绝执行 |

接收端应校验站号、功能码、长度、CRC，并区分正常应答和异常应答；不能假定错误 CRC 一定有应答。

## 4. 控制字 PA_04E

地址：`0x004E`，十进制 78。通过写入位组合触发动作。

| 位 | 掩码 | 功能 | 定义 |
| --- | --- | --- | --- |
| Bit0 | `0x0001` | 定位触发 | 写 1 触发定位运行 |
| Bit1 | `0x0002` | 定位模式 | 0：相对位置；1：绝对位置 |
| Bit2 | `0x0004` | 指令切换 | 0：忽略新指令；1：打断当前运动并执行新指令 |
| Bit3 | `0x0008` | JOG 触发 | 写 1 触发点动运行 |
| Bit4 | `0x0010` | 回零触发 | 写 1 触发回零 |
| Bit5 | `0x0020` | 停止 | 写 1 停止当前运动 |
| Bit6 | `0x0040` | 急停 | 写 1 触发最高优先级急停 |

原手册第 12 页对定位 Bit0、回零 Bit4 标注“不需要清零，重新置 1 即可”；但第 18 页又将回零描述为“上升沿”。重复触发及清位行为有文档歧义，需实机/厂家确认，不推广到所有控制位。程序不得因通信超时自动重发启动触发。

常用控制字：

| 数值 | 动作 |
| --- | --- |
| `0x0001` | 触发相对定位，不打断当前运动 |
| `0x0003` | 触发绝对定位，不打断当前运动 |
| `0x0005` | 触发相对定位，允许打断当前运动 |
| `0x0007` | 触发绝对定位，允许打断当前运动 |
| `0x0008` | 触发 JOG |
| `0x0010` | 触发回零 |
| `0x0020` | 停止 |
| `0x0040` | 急停 |

以上数值由位定义组合得出。软件急停命令不是硬接线急停，也不应把它作为自动故障恢复或自动复位步骤。

## 5. 状态字 PA_004

地址：`0x0004`，十进制 4，通过功能码 `0x03` 读取。

| 位 | 掩码 | 状态含义 |
| --- | --- | --- |
| Bit0 | `0x0001` | 到位 |
| Bit1 | `0x0002` | 回零完成 |
| Bit2 | `0x0004` | 电机运行中 |
| Bit3 | `0x0008` | 故障 |
| Bit4 | `0x0010` | 电机使能 |
| Bit5 | `0x0020` | 正软限位 |
| Bit6 | `0x0040` | 负软限位 |

例如，判断到位使用 `(status & 0x0001) != 0`，判断运行中使用 `(status & 0x0004) != 0`，判断故障使用 `(status & 0x0008) != 0`。

写命令收到应答仅说明寄存器写入得到响应，不代表运动完成；运行结果通过状态字及位置反馈判断。

## 6. 运动参数

### 6.1 定位参数 PA_033～PA_038

原手册第 11、21 页已经明确逐字段定义，不再列为协议缺项：

| 参数 | 地址（HEX / 十进制） | 单位、类型 | 范围 |
| --- | --- | --- | --- |
| 起始速度 PA_033 | 0x0033 / 51 | r/min，uint16 | 0～3000 |
| 加速时间 PA_034 | 0x0034 / 52 | ms，uint16 | 0～2000 |
| 减速时间 PA_035 | 0x0035 / 53 | ms，uint16 | 0～2000 |
| 运行速度 PA_036 | 0x0036 / 54 | r/min，uint16 | 0～3000 |
| 目标高/低字 PA_037/038 | 0x0037/0038 / 55/56 | pulse，int32 | -2147483648～2147483647 |

例如 1000 pulse 为 `0000 03E8`，-1000 pulse 为 `FFFF FC18`。用 10 一次写两个目标寄存器，然后另写控制字触发。上述是驱动协议容量，不是本机允许速度、加速度或行程，不意味着本项目必须实现定位。

### 6.2 JOG 参数 PA_030～PA_032

第 21 页参数表：

| 参数 | 地址（HEX / 十进制） | 单位 | 范围 |
| --- | --- | --- | --- |
| JOG 速度 PA_030 | 0x0030 / 48 | r/min，有符号速度 | -3000～3000 |
| JOG 加速时间 PA_031 | 0x0031 / 49 | ms | 0～2000 |
| JOG 减速时间 PA_032 | 0x0032 / 50 | ms | 0～2000 |

第 12 页明确写控制字 Bit3（0x0008）触发 JOG，运行中修改 PA_030 立即生效。可作为固定方向/速度启停的最小候选方案，但串口触发后的持续运行、停止及重复启动必须现场验证，不把 IO 电平控制示例直接等同串口触发语义。参数表未逐项给出 JOG 字段类型，不伪称它们有独立的数据类型列；有符号单寄存器编码由负速度范围与寄存器格式推导，需测试验证。

原手册另有通过改 DI 功能/常开常闭状态触发 JOG 的示例。本项目不采用周期改写 DI 配置来实现按钮启停，避免改变现场限位和输入用途。

### 6.3 回零参数 PA_040～PA_045

原手册第 16～18 页补齐：

| 参数 | 地址（HEX / 十进制） | 定义与范围 |
| --- | --- | --- |
| PA_040 | 0x0040 / 64 | uint16，方式只能为 17、18、24、29、35，不是其间任意值 |
| PA_041 | 0x0041 / 65 | 回零速度，uint16，0～3000 |
| PA_042 | 0x0042 / 66 | 爬行速度，uint16，0～3000 |
| PA_043 | 0x0043 / 67 | 加减速时间，ms，0～2000；第 16 页类型列为 INTEGER16 |
| PA_044/045 | 0x0044/0045 / 68/69 | 原点偏移高/低字，pulse，int32 |

方式 17＝负限位回零，18＝正限位回零，24＝正向原点回零，29＝反向原点回零，35＝把当前位置清零。35 不产生寻找机械原点的运动，不能代替原点开关验收。

第 18 页说明 DI0/DI1/DI2 可配置原点/正限位/负限位；必须先核对实际接线及极性，禁止启动时自动覆盖 DI 设置。回零不属于当前“开启/关闭”首期必做项。

### 6.4 方向、细分与限位

| 地址 | 定义 | 原手册第 21～22 页 |
| --- | --- | --- |
| 0x0022 | 默认方向 | 0 默认、1 反向；与机械方向一起核验 |
| 0x0023 | 细分 | 400～51200；不自动改为示例 1000 |
| 0x0024 | 限位停车 | 0 停止、1 强制急停 |
| 0x0025 | 软限位有效 | 0 无效、1 有效；仅回零完成后生效 |
| 0x0046/0047 | 正向软限位高低字 | pulse，有符号 32 位范围 |
| 0x0048/0049 | 负向软限位高低字 | pulse，有符号 32 位范围 |

有限行程轴需要有效的独立行程保护；不能为省去回零流程而假定驱动软限位始终有效。首次接入以读取/核对参数为主，不自动写入机械配置。

## 7. 辅助控制 PA_04F

地址：`0x004F`，十进制 79，使用 `0x06` 写入以下命令值。

| 命令值 | 操作 |
| --- | --- |
| `0x0100` | 恢复出厂参数 |
| `0x0200` | 保存当前参数 |
| `0x0300` | 清除当前告警 |
| `0x0400` | 清除当前位置 |
| `0x0500` | 电机使能 |
| `0x0600` | 电机释放 |

需要持久化的参数修改后，使用 `0x0200` 保存；不应在每次运动指令后自动保存。

`0x0600` 按原手册第 22 页辅助控制表表示“电机释放”，但后文示例标题写“电机锁轴”，且说明内容误复制为修改方向，存在冲突。本项目不得把释放当作停止或掉电，也不自动发送此命令；实机使用前核验保持力行为。

## 8. 内部多段控制

| 模式 | 参数范围 | DI 端子配置与触发 |
| --- | --- | --- |
| 内部多段位置 | PA_050～PA_0AE | 配置“位置路径触发”和“路径选择开关 0～3”，由 DI 电平组合选择并触发预存位置参数 |

## 9. 完整报文示例

以下站号均为 `01`。报文全部按 HEX 展示；10 条请求 / 应答的 CRC 已离线核算通过。

### 9.1 读取当前速度

起始地址 `0x000A`（十进制 10），读取 1 个寄存器。

```text
发送：01 03 00 0A 00 01 A4 08
应答：01 03 02 00 C6 38 16
```

示例数值：`0x00C6` = 198 r/min。

### 9.2 读取当前位置

起始地址 `0x0008`（十进制 8），读取 2 个寄存器，高字在前。

```text
发送：01 03 00 08 00 02 45 C9
应答：01 03 04 00 00 13 88 F7 65
```

示例数值：`0x00001388` = 5000 pulse。

### 9.3 修改细分为 1000

地址 `0x0023`（十进制 35），写入 `0x03E8`。

```text
发送：01 06 00 23 03 E8 78 BE
应答：01 06 00 23 03 E8 78 BE
```

### 9.4 触发相对定位

向控制字 `0x004E`（十进制 78）写入 `0x0001`。

```text
发送：01 06 00 4E 00 01 28 1D
```

### 9.5 保存参数

向辅助控制 `0x004F`（十进制 79）写入 `0x0200`。

```text
发送：01 06 00 4F 02 00 B9 7D
```

### 9.6 电机释放

向辅助控制 `0x004F`（十进制 79）写入 `0x0600`。

```text
发送：01 06 00 4F 06 00 BB BD
```

### 9.7 设置定位目标为 1000 pulse

从 `0x0037`（十进制 55）开始写入 2 个寄存器：高字 `0x0000`，低字 `0x03E8`。

```text
发送：01 10 00 37 00 02 04 00 00 03 E8 B1 E3
应答：01 10 00 37 00 02 F0 06
```

该操作只写入定位目标，不自动启动运动；随后写控制字才能触发定位。

## 10. 程序接入顺序

1. 为电机类型建立一个串口连接，配置与驱动器一致的波特率及串口格式。
2. 同一总线按唯一站号访问设备，一个请求完成或超时后再发送下一个请求。
3. 使用 `0x03` 读取状态字、当前位置和速度，验证通信；连接时不自动发送运动或辅助控制命令。
4. 需要运行时，先配置相应运动参数，确认写入应答，再写 PA_04E 触发。
5. 轮询 PA_004 及位置反馈，判断运行、到位、回零完成和故障。
6. 按操作需求发送停止、急停或辅助控制；不因通信超时自动重发运动触发命令。

连接页仅需：共用串口、波特率、串口格式、各驱动器站号。当前单轴连接不要求用户选择 CL / OL 型号；本文不包含双轴驱动器协议。


## 11. 原手册矛盾与仍需实机确认的事项

- 第 12、22 页位表明确回零为 Bit4、停止为 Bit5；第 18～19 页例子文字却写 Bit5 回零、Bit6 停止。例子实际报文 0x0010/0x0020 与位表一致，程序按位表和交叉核对结果处理，不照抄错误文字。
- 回零重复触发描述、“电机锁轴”标题及软件/硬件版本说明有文字不一致，需留存实机版本并对照验证。
- 位置符号与运动参数映射已由原手册明确；尚未确认的是现场型号/工作方式、参数实际值、机械方向/传动/行程、开关接线、停止行为、断线保护及位置读取一致性，不再笼统写成“协议全部未知”。
- 同一总线固定两个电机，按项目 AGENTS.md 实现；不因手册支持更多节点增加动态设备管理。

## 12. 厂家调试软件的用途与限制

调试软件说明共 5 页：第 2 页选择 CL/OL 型号并展示站号 1、38400；第 3 页识别 COM 端口与通信状态；第 4～5 页演示读取/写入参数和重新上电核验。

这些用于初次现场比对和故障排查，不表示程序应照搬厂家全部调参页面。站号 1、38400 和电流示例都不是两台实物的既定值；不复制电流、DI、细分参数到应用默认配置。厂家工具与本程序不得同时占用同一串口。
