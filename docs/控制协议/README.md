## 阅读与接入原则

- 先核对实物型号、供电和接口电平，再接通信线。
- 通信端口打开、收到有效报文、设备允许运动是不同状态。
- 未经确认，不自动复位、清错、写当前位置、调用记忆位置或执行运动。
- 本目录只整理资料，不包含硬件驱动实现，也不表示已完成硬件验收。
- 后续新增电机、夹爪、传感器采集器等资料时，按设备分别整理，不共用未经证实的协议参数。
