## 二、需要补充的最小资料

### 2.1 部署配置

请提供目标电脑上的端口分配表和实际通信设置；扫描顺序不作为设备身份。

| 配置路径 | 需要确认的值/依据 |
| --- | --- |
| `motors.serial` | 电机共用端口、两驱动器实际波特率和串口格式 |
| `motors.motor1` / `motor2` | 两个不同站号，与接线和驱动器设置一致；默认 1/2 只是分配建议 |
| `motors.operation.motor1/motor2` | 各轴实际用途、方向、允许速度、加减速、最长运行时间及有限行程保护 |
| `lift.serial` / `interface` | 实际控制器型号/固件、RS232 或 RS485、端口和通信设置 |
| `tension` | 端口、站号、输出单位、实际小数位/标定；物理安装位置及测量方向 |
| `displacement` | 端口、站号、实物模块型号 P/G、通道、读取方式、量程和水平/垂直机械角色 |
| `array` | USB 或串口、两采集卡 REV 绑定；串口模式每卡独立端口 |

不得用协议编码范围代替机械安全范围，不得将任意 N 通道映射成法向力，也不得将 rpm 直接当作 mm/s。

### 2.2 电子皮肤

- 厂家 USB SDK、驱动安装包、支持的操作系统/架构及最小可运行收数示例；如果实际走串口，提供串口格式和上报条件。
- 卡型号/固件、VID/PID、接口/端点、REV 选择方式和授权/握手流程。
- 至少一条厂家确认正确的完整原始行包及一帧数据；CRC 参数、覆盖范围和结果字节序。不得通过猜测 CRC 后接受数据。
- 原始点值的符号/电压含义、异常值、安装朝向、像素真实面积、接触阈值及力标定公式/材料。

当前厂家资料目录只有通信说明，参考项目 `/Users/yh/project/code` 未见配套 USB/REV/CRC 实现。若 SDK 在其他位置，需要给出该位置或提供文件。

### 2.3 升降与气压

- 明确首页升降“开启”对应上升、下降、使能还是到某位置，不能由软件自行选择。
- 确认动作应答、停止/到位反馈、实际行程、软硬限位和失联后行为；若走 RS485，补充实际读数查询及通信参数。
- 夹爪气压的实际写入接口、实际反馈通道、单位/量程及超压保护。没有接口时滑块继续禁止写入。
- 初始化/回零/置零各自应作用于哪些真实设备、必要前置条件和成功反馈；不能组合发送未知写指令。

## 三、收到资料后的收尾顺序

1. 先确认端口/站号与设备型号，补部署配置，不自动启动或使能。
2. 按厂家示例接阵列驱动及 CRC，验证两卡会话隔离、完整帧、断线清零、禁止旧帧续接。
3. 按安装角色与标定接八项工程量；有效真实零保留质量，失效占位零不可写为正常样本。
4. 确认升降/气压/初始化等语义后逐项实现，定义可验证的待机判据，满足所有必需设备才能显示整机已就绪。
5. 明确联动动作顺序和所需测量集合后启用试验开始；启动前校验，记录会话/配置及来源；必要测量失效时停止并结束记录。
6. 完整软件回归后，在人员确认机械安全、硬接线急停及有效行程保护的条件下实施现场验收。不得自动或无人值守运行该步骤。
