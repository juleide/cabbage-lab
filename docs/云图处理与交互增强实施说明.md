# 云图处理与交互增强

实施前确认的完整方案见 [云图处理与交互增强实施计划](云图处理与交互增强实施计划.md)。本文记录实际实现约定与验证结果。

## 本轮范围

原始／显示阵列分离、逐点零点修正和取消、可保存的显示范围、点选读数、阵列统计及采集诊断。维持既有模拟源、协议解析、25Hz 采集和最多 10Hz 发布／绘制；不增加真实硬件接口、标定、滤波、曲线、阵列落盘或数据库迁移。

## 实现约定

### 原始与显示数据

- PressureFrame.values 保留未经显示处理的 4096 个原始 16 位整数。
- displayValues 是独立的显示数据，可为浮点数和负数。没有基线时复制原始值；有基线时逐点相减。
- 原始／显示阵列各自计算最小值、最大值、平均值和最大值位置。同值最大点取行优先的第一个。
- processingVersion 随基线更新或清除递增，前端拒绝旧处理版本的帧。现有标量参数、数据库和 CSV 不变。

### 零点修正

- pressure.zero.start 只在在线、阵列新鲜、未急停、试验停止且所有执行机构关闭时接受。
- 从请求后完成的 25 个新有效完整帧中逐点求平均；只维护累计和与计数，3 秒未完成报超时。
- 新基线成功前保留旧基线，超时不覆盖旧基线。修正收集中阻止启动执行机构和联动，急停与停止仍可用。
- pressure.zero.clear 同时取消收集并清除基线。模式切换、初始化、急停、源重建及控制端重启清除基线；普通停止试验保留。
- 基线不落盘，不在新会话自动恢复。
- 首页“传感器置零”只处理既有标量模拟值，不再清空阵列原始源。阵列修正从“云图详情”独立操作。

### 显示与偏好

- 首页新增图标式详情入口，在既有色标下方一行显示选点读数，避免额外挤占云图高度。
- Canvas 以实际边界将鼠标／触摸坐标映射为 64 × 64 点位；界面显示 1～64 行列。模式切换清空选点。
- 详情弹窗包含放大云图、原始／修正值、两组统计、帧时间、修正状态／进度和修正操作。详情弹窗保留紧急停止入口，修正收集中也可直接急停。
- 读数与统计来自实际绘制的同一完整帧。暂停、失联和超时明确提示非实时状态。
- “云图显示”设置支持线性上下限和恢复默认 0～4095。上下限为有限数字，范围 −65535～65535，且下限小于上限。
- 超出显示范围只钳制颜色，不改变原始值、修正值与统计。色标标注原始／修正值，不使用物理压力单位。
- 显示范围与主题共存于 ui.json，通过同一原子写入队列保存，避免互相覆盖。旧文件仅有 theme 时沿用默认范围。

### 诊断

- pressure.status 提供来源对应的模式、修正状态、有效帧数、CRC 错误、残帧丢弃、实际采集帧率、最后完整帧时间及异常。
- 设置页独立订阅阵列事件以计算界面接收帧率，并最多每秒刷新诊断；不依赖首页 Canvas 是否挂载。
- 阵列帧通过 ref 传递，不放入应用顶层 React 状态；Canvas／局部读数最多每秒更新 10 次。

## 验证与边界

仅更新既有轻量检查以适配接口，不新增测试套件。执行类型检查、构建和既有 backend:check，确认原始值不变、逐点平均、负值保留、取消修正、超时保留旧基线、修正互锁以及原有记录／导出兼容。

真实 USB、厂家 CRC、标定文件和压力单位不在本轮范围。图形界面还需在用户本机查看实际布局与交互，不将构建通过等同于视觉验收。

本轮类型检查、构建及既有轻量／后端短流程检查均通过；未新增测试套件。
