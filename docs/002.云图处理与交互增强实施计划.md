# 云图数据处理与交互增强实施计划

> 本文记录实施前确认的计划。实际实现约定与验证结果见 [云图处理与交互增强实施说明](云图处理与交互增强实施说明.md)。

## 一、目标与范围

本轮落实以下七项能力：

1. 原始阵列与显示阵列分离。
2. 真正的逐点零点修正。
3. 取消零点修正。
4. 可保存的云图显示范围。
5. 点选查看原始值、修正值和坐标。
6. 阵列最大值、最小值、平均值及最大值位置。
7. 采集诊断信息展示。

保持当前首页三栏布局、云图尺寸、25Hz 模拟采集和最多 10Hz 显示，不新增真实设备接入、滤波、标定、曲线、阵列落盘或数据库迁移。

## 二、Python：原始数据、零点修正与统计

### 1. 分离数据

完整帧解析完成后分为两条数据路径：

```text
原始阵列 ───────────────────→ 保留原始值
    └─ 减去逐点基线（可选） → 显示阵列 → 统计与颜色映射
```

- 现有帧中的 `values` 继续表示未经修正的原始值，不覆盖、不截断。
- 新增 `displayValues`，允许浮点数和负数。
- 无零点修正时，两者数值一致。
- 原始值不受显示范围、颜色映射和零点修正影响。
- 不改变现有八项标量参数的计算、试验记录及 CSV 格式。

### 2. 实现阵列零点修正

新增专门的“阵列零点修正”，不与首页原有的“传感器置零”混用。

- 启动前检查：控制端在线、阵列正常、试验停止、全部执行机构关闭、未急停。
- 界面提示用户确认传感器处于无负载状态。
- 收集启动后 25 个有效且不重复的完整原始帧，逐点计算平均值作为基线。
- 默认超时 3 秒，不使用残帧、旧帧或修正后的数据。
- 只保存累计和、计数和最终基线，不缓存全部历史帧。
- 修正成功后，后续显示值为“当前原始值减去对应点基线”。
- 重新修正期间保留原有基线；新修正失败时，不覆盖仍有效的旧基线。
- 修正期间禁止启动执行机构或联动试验；急停、停止操作始终可用。

原有“传感器置零”仍处理标量模拟参数，但取消它让阵列模拟源直接输出全零的行为。阵列零点修正不会修改原始模拟源。

### 3. 修正生命周期

- “取消修正”清除基线，立即恢复原始值显示；收集中点击则同时取消收集。
- 切换按压／抓取、重新初始化、急停、控制端重启或数据源重新建立时，取消收集并清除基线。
- 普通停止试验不清除基线。
- 基线只在当前控制会话内有效，不保存到磁盘，不在启动后自动恢复。
- 使用处理版本号区分修正前后帧，防止旧帧在界面中覆盖新结果。

### 4. 阵列统计

Python 对原始阵列和显示阵列分别计算：

- 最小值。
- 最大值及所在行列。
- 平均值。

最大值存在多个相同位置时，取行优先顺序中的第一个点。零点修正后的负值保留在统计中，不强制归零，也不标为真实压力或力。

## 三、前端：查看交互、显示设置与诊断

### 1. 云图与详情

首页不新增大块面板，避免再次压缩云图。

- 保留按压／抓取切换和现有色标。
- 在卡片标题区域增加图标式“云图详情”入口。
- 云图支持点击和触摸选点，标记所选位置。
- 在色标下方增加一行紧凑读数：行、列、原始值、修正值；未选点时显示简短操作提示。
- 用户界面坐标采用 1～64；内部数组索引仍为 0～63。
- 坐标根据 Canvas 实际显示边界换算，兼容窗口缩放；边界外点击不选点。
- 模式切换后清除选点。

详情弹窗展示：

- 放大的云图与选中点读数。
- 当前数据来源、帧时间、修正状态及收集进度。
- 原始／显示阵列的统计信息。
- “阵列零点修正”和“取消修正”操作。

暂停、超时、离线时，读数和统计明确标为非实时；不继续更新成看似正常的实时结果。

### 2. 显示范围设置

在设置页新增“云图显示”分类：

- 显示下限、显示上限。
- “保存并应用”和“恢复默认”。
- 默认范围保持 0～4095。
- 两个值必须有限、位于 −65535～65535，且下限小于上限。
- 本轮只实现线性、固定范围映射，不加入自动范围或对数模式。
- 范围外数值映射为最低／最高颜色，但原始值、修正值和统计值不截断。
- 色标显示当前上下限，单位为“原始值”或“修正值”，保留模拟来源标识，不使用 kPa。

显示范围属于界面偏好，与主题一起保存到本机 `ui.json`。扩展现有写入逻辑，确保保存主题不覆盖显示范围，反之亦然。旧文件只有主题时自动采用默认范围，无需用户迁移。

### 3. 采集诊断

在现有“运行与诊断”中增加：

- 当前阵列来源和模式。
- 最近完整帧时间。
- 有效采集帧率、界面接收帧率，分别标注。
- 累计有效帧数、CRC 错误数、残帧丢弃数。
- 当前零点修正状态及最近采集异常。

诊断信息最多每秒刷新一次。进入设置页后，即使首页云图已卸载，仍可读取阵列诊断；不把 4096 点阵列存入应用顶层 React 状态。

## 四、接口与实施顺序

### 接口调整

- `PressureFrame`：保留原始 `values`，增加 `displayValues`、处理版本、修正状态和两组统计。
- 阵列状态：增加修正收集进度及采集诊断数据。
- 增加开始阵列零点修正、取消修正、读取阵列诊断的受限请求。
- preload 增加显示范围读取／保存接口；仍不向渲染层开放通用文件读写。
- 原始值与显示值分别校验：原始值保留 16 位整数约束，显示值允许有限浮点数及负数。

### 实施步骤

1. 完成 Python 数据分离、基线收集、生命周期约束和统计。
2. 更新共享类型、请求白名单、状态快照及阵列事件。
3. 接入 Canvas 显示阵列、选点和详情弹窗。
4. 增加云图显示设置、偏好兼容和诊断展示。
5. 更新 README 和实施文档，明确模拟与未标定数据的含义。

## 五、必要确认与验收

不新增测试套件，不进行长时间运行测试。仅做类型检查、构建及一轮短流程确认：

- 修正前后原始值不变，显示值按基线变化；取消后恢复原始值。
- 25 帧收集、超时、模式切换、急停和重启的处理符合上述规则。
- 修改显示范围只改变颜色，不改变读数；主题与范围保存互不覆盖，重启后恢复。
- 窗口缩放后选点仍准确，统计与选中点来自同一显示帧。
- 暂停／离线／超时不显示为实时；诊断页能在首页未显示时正常刷新。
- 不改变数据库结构、现有标量记录及 CSV 导出格式。
