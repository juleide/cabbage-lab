## 测试保留与迁移

| 被移除的旧 UI 测试 | 当前保留覆盖 |
| --- | --- |
| 电机配置编辑与迁移 | `tests/backend/hardware-config-test.py` 的 v1 内存迁移、非法旧值保留、安全绑定失效等测试；当前设备连接页的配置持久化测试仍保留 |
| 独立电机控制面板 | `tests/backend/motor-control-test.py` 的驱动反馈、启动/停止、运行保护、锁定取消待启动等测试；`homepage-motors.spec.ts` 保留真实首页路径 |
| 独立运动诊断面板 | `tests/backend/hardware-motion-test.py` 的只读会话、停止、联锁、JSONL 锁定/退出等测试 |
| 运动安全规划面板 | `tests/backend/motion-safety-test.py` 的校验、持久化、只规划不执行等测试 |
| 独立传感器采集面板 | `tests/backend/hardware-sensors-test.py` 的真实反馈解析、采集记录、相对置零、超时及断开等测试 |

旧 `motion.spec.ts` 中跨 Electron IPC 的锁定停止与诊断联锁断言迁移到 `tests/desktop/connection-safety.spec.ts`。使用临时 fake serial，不依赖任何已删除面板，检查连接只读、两站停止帧、端口关闭、锁定后 IPC 拒绝及无自动重连。

`hardware.spec.ts` 不删除：保留串口扫描、配置保存/恢复、绑定、模块选择、未保存离页确认和急停后可访问。更新其 IPC 夹具以支持当前 `ConnectionStatus` 的 motion/sensors 轮询，并将不再渲染的“本次读取”断言改为当前只读验证边界提示。

核对覆盖时发现一条已有 Python 安全测试仍要求“控制器重启不连接已保存设备”，与当前自动连接需求冲突。已改为单独恢复 `MotionSafetyStore` 验证安全草稿持久化；保存/离线规划不打开串口的断言继续保留。不修改生产自动连接行为，也不以删除失败断言掩盖故障。
