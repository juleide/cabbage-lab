# 运动安全配置与现场核验清单

日期：2026-11-01。对应 D3 子批次。**本文件和配置草稿不是安全认证，也不授权真实运动。**

后续 D4a 已补充电机原始位置读取，详见 [电机原始位置反馈与验收说明](009.电机原始位置反馈与验收说明.md)。原始位值仍未经符号、物理单位与现场标定核验，不解除本文件的运动阻断。

## 1. 当前交付与限制

保留 D2 的电机状态、升降 RS232 监听及受限停止诊断，新增：

- 「设备连接 → 运动安全」独立页面，编辑两个电机及一个升降的安全草稿。
- 数据目录下 `config/motion-safety.json` 的版本化、严格校验及原子替换保存；不会修改 `hardware.json` 的版本或结构。
- 按目标显示缺项、连接绑定、反馈及实现层阻断原因。`canExecute` 始终为 `false`，不存在获取执行许可或发送运动的 RPC。
- 已保存完整且匹配的目标可进行纯离线坐标计算，输出脉冲/高低字或升降 ASCII 位置数值；不生成串口报文、不读取实际位置、不打开串口。

真实启动、使能、释放、回零、升降上升/下降和目标运动仍未开放。D3 不是完整运动控制或整机安全联锁阶段。

## 2. 配置保存与手动修改

文件路径相对于应用数据目录，而非仓库工作目录：

```text
config/hardware.json         现有设备连接配置，schemaVersion = 1
config/motion-safety.json    新增运动安全草稿，schemaVersion = 1
```

空白示例见 `docs/examples/motion-safety.example.json`。未知参数全部使用 `null`，未知材料使用空字符串；不提供可直接运行的示例机械行程、速度或时长。

文件不存在时使用内存空白草稿，只有显式保存才创建文件。损坏、未知字段、未知版本、重复 JSON 字段、非有限数字、错误类型或超过 64 KiB 的文件都会报错并保留原文件；不以默认值覆盖损坏文件。

手动编辑顺序：

1. 停止试验及已有诊断，断开真实设备，并现场确认机械安全。
2. 保存或另行备份尚未保存的界面草稿，停止控制端或关闭应用，备份原配置文件。
3. 按示例的完整结构修改 JSON；整数与小数使用 JSON 数字，不用字符串或布尔值替代。不要添加 `enabled`、`canExecute` 或其他未定义开关。
4. 重启控制端应用修改。若正在运行时修改安全文件，新的离线规划及界面保存会被拒绝，避免静默覆盖文件；“重新载入安全草稿”仅读取后端已加载快照，不能代替重启加载磁盘新值。
5. 检查材料记录、连接绑定及能力评估。即使所有字段完整，真实运动仍禁用。

界面保存同时校验安全版本和连接配置版本，拒绝旧页面覆盖新配置。磁盘摘要检查用于发现外部修改，原子替换防止半写入；这不是跨进程文件锁，请勿同时通过程序和外部编辑器写文件。

## 3. 字段约束

### 3.1 全局记录

| 字段 | 含义与约束 |
| --- | --- |
| `schemaVersion` | 固定整数 1 |
| `hardwareVersion` | 空或 SHA-256；由页面显式记录当前已加载的电机/升降连接配置指纹 |
| `machineId` | 人工记录设备/工装编号；不替代读取设备身份或序列号 |
| `reviewedBy` | 材料记录审核人，不是自动认证或电子签名 |
| `reviewedAt` | 空或不晚于今天的 `YYYY-MM-DD`；完整规划需填写 |
| `evidence.*` | 材料引用，最多 512 字符；写报告编号、文件及章节，不写密码 |

指纹包含 `hardware.json` 中整个 `motors` 和 `lift` 分类，包括站号、端口和串口参数。任一分类变化都使原草稿绑定不匹配；拉力、位移和电子皮肤配置不参与此指纹。手动修改连接文件在重启加载后生效，界面保存连接配置则立即重新评估。

“记录当前连接配置绑定”只记录数据关联，不能证明现场未换设备、参数已下发或材料真实有效；更换硬件必须重新核验标定和材料，不能只更新哈希。

| 材料引用字段 | 应覆盖的现场事实 |
| --- | --- |
| `emergencyCircuit` | 硬接线急停回路、制动/动力切断行为、复位条件及验收记录 |
| `disconnectProtection` | 通信失联、适配器拔除、程序退出/强杀及设备侧看门狗/制动行为 |
| `mechanicalLimits` | 两个电机和升降各自允许行程、方向、零点、限位、碰撞风险及测量结果 |
| `motorParameters` | 当前驱动型号/固件、逐寄存器运动参数映射、单位、标定、限速及实测停止行为 |
| `liftFeedback` | 接口/固件、位置单位、反馈周期、停止及到位标志、断线行为与实测结果 |

程序不会读取或鉴定引用材料内容，也不会因填入路径就把 `evidenceVerified` 改为真。

### 3.2 两个电机的规划约束

`motor1`、`motor2` 固定存在，不提供增加/删除轴；共享连接总线的规则不变。

| 字段 | 含义与约束 |
| --- | --- |
| `minimumMm` / `maximumMm` | 人工标定坐标的行程，必须有限且上限大于下限 |
| `maxStepMm` | 正数，单次规划距离上限，不能大于配置行程跨度 |
| `maxDurationMs` | 整数 1～60000，本地规划时长上限，不是到位时间预测或厂家保证 |
| `pulsesPerMm` | 正数，每 mm 脉冲数，需现场确认传动及细分 |
| `direction` | 严格整数 `1` 或 `-1`，不得用 `1.0` 或布尔值替代 |
| `zeroPulse` | 整数 0～2147483647，人工坐标零点对应的设备脉冲 |
| `maxSpeedRpm` | 正数，仅用于离线请求的速度上限；不代表已确认运行速度寄存器及单位映射 |

离线关系：`pulse = zeroPulse + direction × positionMm × pulsesPerMm`。

起点和目标都必须在配置行程内，距离必须大于 0 且不超过单次上限。标定行程端点不得越过保守非负 31 位区间；计算得到的实际起点/目标脉冲必须为整数，不静默舍入。

当前资料未明确完整有符号目标约定，因此离线工具保守限制在 0～2147483647；这不是声明设备仅支持 31 位，也不是实际机械行程。高字、低字按已知目标寄存器顺序计算，但不生成 `0x10` 或定位触发请求。速度字段不套用“起始速度 0～3000 r/min”作为未确认运行速度上限。

### 3.3 升降规划约束

| 字段 | 含义与约束 |
| --- | --- |
| `minimumMm` / `maximumMm` | 整数 mm，0～9999 且上限大于下限 |
| `maxStepMm` | 正整数 mm，不超过配置行程跨度 |
| `maxDurationMs` | 整数 1～60000，本地规划时长上限 |
| `feedbackMaxAgeMs` | 整数 1～60000，待实测确认的反馈新鲜度要求草稿 |
| `stopTimeoutMs` | 整数 1～60000，待实测确认的停止等待要求草稿，不是已停证明 |

0～9999 mm 只来自 `DDD.d` cm 的编码容量，不能作为默认允许行程。离线输入必须为整数 mm；例如人工目标 123 mm 转换为 `012.3` cm，不构造 `0x80` 运动帧。

**上述新时序字段当前不替换 D2 的轮询阈值或停止 ACK 等待，也未实现真实运行看门狗。** D2 仍按已有诊断策略工作，不能把配置存在当作保护机制已经执行。

## 4. 能力评估与离线计算

RPC 均经过主进程研发权限校验：

| 方法 | 用途 |
| --- | --- |
| `hardware.safety.get` | 读取已加载草稿、配置版本及评估，不续期权限 |
| `hardware.safety.status` | 只读评估，不续期权限；页面仅在运动安全分类可见时轮询 |
| `hardware.safety.save` | 显式保存草稿；需试验空闲且结束诊断/采集/验证，检查两种预期版本 |
| `hardware.safety.preview` | 只对完整、已绑定、已保存的目标进行离线计算，并记录版本与结果 |

`canPreview` 只表示该目标的草稿和连接配置可以参与离线计算，**不检查机械可行性或轨迹能否在所填时长内完成**。规划起点为人工输入，不是从驱动器读取的实际位置。界面未保存、配置不匹配、损坏或检测到外部修改时不得把旧结果当作当前结果。

`canExecute` 始终为 `false`。固定阻断包括执行链路未实现、材料未核验、设备身份未核验、电机参数映射或升降停止/断线语义未确认；还展示未连接、反馈无效、锁存、运行/软限位及软件急停等条件。电机诊断尚无可用于运动许可的位置反馈，升降单位也未实机核验。

安全草稿错误不影响已有停止/急停接口。安全文件不能增加设备数量、改变端口规则、生成真实写寄存器入口或通过一个配置开关启用运动。

保存及离线结果以版本/结果日志写入现有 SQLite 运行日志，不进入模拟试验数据或 CSV；当前不是历史安全配置归档、材料签核系统或完整运动审计数据库。

## 5. 开放真实运动前的核验清单

1. 从厂家/现场获取当前型号和固件对应的电机速度、加减速、JOG、定位、回零逐字段地址/宽度/单位/范围及应答测试向量；明确有符号目标和原点约定。
2. 实测两个电机各自脉冲/mm、正反方向、零点、机械行程和软/硬限位；明确使能/释放对负载、抱闸及下坠风险的影响。
3. 实测升降接口与位置单位、上/下持续运行及普通停止行为、反馈周期、已停/到位标志及通信中断制动；不把 09 清错当心跳，也不猜测 RS485 查询。
4. 验证独立硬接线急停、断线制动和设备侧看门狗。软件无法保证操作系统阻塞或进程被强杀时发出停止。
5. 再实现会话级、短有效期的运动许可、实际位置/新鲜度检查、停止/断开作废许可、通信失败安全停机和单轴限时运行；保存草稿不能充当执行许可。
6. 使用假串口覆盖失败与竞态后，现场以安全机械环境逐轴低风险验收，再考虑与传感器并发、整机运动和真实试验映射。
