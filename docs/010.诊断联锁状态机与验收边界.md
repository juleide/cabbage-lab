## 2. 会话内状态机

`hardware.motion.status` 各会话增加 `diagnosticGuard`：

| 字段 | 含义 |
| --- | --- |
| state | waiting / observing / tripped / closed |
| reason | 首次触发原因，未触发为 null |
| trippedAt | 主机触发时间，秒；未触发为 null |
| intervalMs | 固定 50，后台目标检查间隔，不保证实时调度 |
| physicalStopConfirmed | 固定 false |

状态转换：

- 会话创建：waiting；打开串口不等于在线。
- 后台观察到至少一份目标反馈：observing，仅表示开始检查已有反馈，不表示两个电机都在线、位置完整或可运动。
- 已收到反馈过期、电机故障/运行/软限位、升降错误反馈或诊断通信异常：tripped，保留首次原因，锁存故障，请求停止并关闭该会话。
- 正常断开：closed；故障触发后保持 tripped，不因停止回显、后续新鲜读数或关闭端口变成正常。
- tripped 会话最终显示 failed；人工停止/权限锁定仍沿用旧流程，不自动当作诊断阈值触发。

没有复位 RPC。旧会话不恢复；线程退出后允许重新人工连接，形成新 sessionId，只开始新的只读诊断，不清除驱动故障、不续跑、不获得运动许可。需要跨重启保留的物理故障和验收许可仍未实现。

## 3. 触发条件与响应

### 已收到反馈的新鲜度

后台观察线程每约 50 ms 检查一次。使用主机单调时钟和 D2 既有阈值 `max(1000, 3 × intervalMs)` 毫秒，分别检查状态/升降反馈以及电机原始位置。状态刷新不刷新位置，位置刷新不刷新状态。

任何已收到反馈超出阈值，都会对该会话全部目标请求停止：电机为两个站号的软件急停，升降仍仅为已知普通停止帧。随后关闭端口，不自动重连。

该检查不依赖 UI 轮询、状态 RPC、主试验 tick 或模拟是否急停；观察线程不直接访问串口和 SQLite，仅操作既有线程安全停止队列与审计缓冲。真正的串口操作仍由原所有者线程完成。

**无首份反馈时不启动猜测的首帧超时。** 电机由既有事务超时发现无应答；升降没有已确认主动上报周期，因此可保持 waiting，不能把它解释成在线或正常。即使曾收到一份升降高度，也无法证明固定上报：一份数据过期结束诊断是保守的本地策略，可能导致设备静止时关闭，不能认为厂家支持这个反馈时限。

### 故障、运行与限位

电机状态字显示故障、运行、正软限位或负软限位时，保留对应触发位名称，请求两个站号停止并关闭总线会话，不继续轮询。只读诊断没有授权外部运动；因此即使运行由手柄、其他主机或外部输入发起，也会触发。这是本批次有意收紧的诊断策略，连接前必须告知现场人员。

升降任何 09 错误反馈均触发，包括 00，因为协议未确认上行 00 表示无故障。不发送 09 清错，不发送未知查询。

### 通信异常

异常路径会记录联锁触发并请求停止，但当读/写/打开调用已经异常时，仍沿用立即失效、结束会话的路径，**不保证执行最后入队的停止**，未发送命令标为 unknown。不为了发送停止而重开端口，不重试写入。

后台发现过期但所有者仍在可取消等待时，停止请求可抢占该等待，进入原有停止队列；已阻塞在操作系统驱动中的调用不能由普通线程可靠打断。后台 50 ms 不是停止送达上限，停止 ACK 等待、写入和关闭仍受原传输层约束。

## 4. 锁存、审计与界面

- 首次触发记录到有界审计缓冲，由主控制线程写既有运行日志；后续同类反馈不重复生成新的联锁停止。
- 原停止队列按目标合并，普通停止不能降级软件急停。显式人工重复停止仍按原规则处理，不属于自动重试。
- 触发即将会话改为 disconnecting，使所有旧反馈不可用；关闭调用阻塞时也不保持旧值为 valid。
- 界面显示 waiting/observing/tripped/closed 及首次原因；即使已收到停止回显，也固定提示机械停止未确认。
- 安全能力评估增加 DIAGNOSTIC_INTERLOCK 阻断；完整安全草稿不能解除该阻断，离线计算仍不执行动作。
- 一个会话的触发只停止该会话：电机总线两个目标一起停止，升降会话独立。**尚未实现跨设备故障联锁**，不能把当前行为当作整机安全闭环。
- 未新增配置字段或改变 D3 草稿时限含义；D3 的 feedbackMaxAgeMs/stopTimeoutMs 仍不控制此诊断机制。

桌面新增真实 Electron IPC → Python → 假串口用例：连接仅读取，注入运行位后自动向两个站号发送软件急停、关闭端口、显示锁存原因、隐藏旧位置，停止结果不宣称机械停止。
